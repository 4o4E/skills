description: "针对高可信度一手来源调查问题，并将发现记录到仓库中的 Markdown 文件。适用于用户要求研究某个主题、收集文档或 API 事实，或将阅读工作委派给后台代理。"
---

启动一个**后台代理**开展研究，这样你可以在它阅读资料时继续工作。

它的工作是：

1. 根据**一手来源**(官方文档、源代码、规格说明、第一方 API)调查问题，而不是依据二手文章。每项声明都要追溯到其来源。
2. 将发现写入一个 Markdown 文件，并为每项声明注明来源。
3. 将文件保存到仓库现有的研究笔记位置；遵循已有惯例。如果没有惯例，就选择合理位置并说明保存位置。
