# 分流标签

这些技能使用五个规范分流角色。本文件将这些角色映射到本仓库议题跟踪系统实际使用的标签字符串。

| mattpocock/skills 中的标签 | 我们的议题跟踪系统中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护人员需要评估这个问题 |
| `needs-info`               | `needs-info`         | 正在等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，已准备好交给 AFK 代理 |
| `ready-for-human`          | `ready-for-human`    | 需要由人来实现 |
| `wontfix`                  | `wontfix`            | 不会采取行动 |

技能提到某个角色时（例如“应用 AFK 就绪分流标签”），使用此表中对应的标签字符串。

编辑“我们的议题跟踪系统中的标签”列，使其符合你实际使用的词汇。
