---
name: handoff
description: 将当前对话整理成交接文档，供另一位代理继续处理。
argument-hint: "下一次会话将用于什么？"
disable-model-invocation: true
---

编写一份交接文档，总结当前对话，使一个新的代理能够继续工作。保存到用户操作系统的临时目录（`$TMPDIR`，否则使用 `/tmp`；Windows 使用 `%TEMP%`），不要保存在当前工作区。

在文档中加入“建议使用的技能”部分，列出下一位代理应调用 Skill 工具使用的技能。

不要重复其他产物（规格说明、计划、ADR、议题、提交、差异）中已记录的内容。请使用路径或 URL 引用它们。

删去任何敏感信息，例如 API 密钥、密码或个人身份信息。

如果用户提供了参数，就将其视为下一次会话要关注内容的描述，并据此调整文档。
