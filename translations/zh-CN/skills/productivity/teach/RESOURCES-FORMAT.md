# RESOURCES.md 格式

`RESOURCES.md` 是为此主题整理的可信资料。讲解所需的知识应来自这里，而不是来自模型的臆测。智慧应来自这里列出的社群。

## 结构

```md
# {主题}资源

## 知识

- [书籍：《力量训练的科学与实践》，作者 Zatsiorsky 和 Kraemer](https://example.com)
  介绍训练安排和身体适应的基础文本。适用于：周期安排、恢复和强度区间相关内容。
- [文章：“我应该训练多少？”，作者 Greg Nuckols（Stronger By Science）](https://example.com)
  基于证据回顾训练量基准。适用于：每个肌群每周训练组数的目标。

## 智慧（社群）

- [r/weightroom](https://reddit.com/r/weightroom)
  信息质量高、会清理伪科学内容的子版块。适用于：训练计划评估、训练停滞问题排查。
- 本地：{健身房名称}周二力量训练课
  适用于：获得举重动作的即时指导反馈。
```

## 规则

- **只选高可信度资料。** 优先选择一手资料、公认专家、同行评审研究，以及管理严格的社群。如果某个资源只是把营销内容包装成教育内容，就不要收录。
- **为每项资料加注说明。** 只有链接没有用处。用一行文字说明它涵盖什么内容，以及何时使用。
- **按知识与智慧分组。** 这与 [SKILL.md](./SKILL.md) 中的教学理念一致。某项资料只属于其中一组也可以。
- **明确指出资料缺口。** 如果某个学习任务需要的领域没有优质资料，就添加 `## 缺口` 部分，列出缺少的内容。这有助于之后继续查找。
- **严格删减。** 如果某项资料后来被证明错误、浅薄或与学习任务无关，应直接删除，不要把它埋在列表中。宁可保留五项精挑细选的资料，也不要列出三十项平庸的资料。
- **记录社群偏好。** 如果用户选择不加入社群，请在此记录，避免未来会话继续向他们推荐社群。
