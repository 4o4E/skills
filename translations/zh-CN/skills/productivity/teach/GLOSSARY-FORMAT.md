# GLOSSARY.md 格式

`GLOSSARY.md` 是此教学工作区的规范用语。所有讲解、练习和学习记录都应遵循其中的术语。建立词汇表本身也是学习的一部分：将概念浓缩为精确的定义，说明用户理解了它。

## 结构

```md
# {主题}词汇表

{用一两句话说明本词汇表涵盖的主题。}

## 术语

**肌肉肥大**：
肌肉在多次训练中持续承受机械张力和代谢压力后产生的生长。
_避免使用_：增肌、练壮

**渐进式超负荷**：
通过负重、训练量或强度，逐步增加肌肉所承受的要求。
_避免使用_：练得更努力、升级

**RPE（主观用力程度）**：
用 1 到 10 自评一组练习的难度；10 表示力竭，8 表示还可以再做两次。
_避免使用_：努力程度评分、强度评分
```

## 规则

- **只有在用户理解一个术语后才添加。** 词汇表记录的是已经压缩整理的知识，不是供用户学习时阅读的词典。如果用户刚刚接触一个概念，请等他们能够正确使用后，再将其收入词汇表。
- **明确选择用词。** 如果同一个概念有多个说法，请选出最佳用词，并列出其他应避免使用的别名。这样可以精简表达。
- **定义要精确。** 限定在一两句话。说明术语_是什么_，不要说明它有什么作用或如何使用。
- **定义中使用词汇表已有术语。** 某个术语收入词汇表后，其他地方也应尽量使用它，包括其他定义中。这会让复杂术语更容易理解。
- 当自然形成不同类别时，使用小标题分组（例如 `## 解剖学`、`## 训练安排`）。如果术语彼此相关，也可以使用不分组的列表。
- **明确指出歧义。** 如果某个术语在相关领域中有宽泛用法，请说明如何确定其含义：“在此工作区中，‘组’总是指有效训练组；热身组会另外记录。”
- **随着理解深入而修订。** 用户第一周编写的定义可能到第六周时已经错误。请直接更新定义，不要保留过时条目。
